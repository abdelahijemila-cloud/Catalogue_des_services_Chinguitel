Gestion du catalogue Chinguitel

Modifier les informations du catalogue sans toucher au code du site.

1. Ouvrir le catalogue

Utilisez une clé d'accès GitHub dédiée à ce catalogue. Elle permet à cette page de lire et d'enregistrer les modifications directement.

2. Modifier les informations

Changez les prix, volumes, minutes, SMS, validités, codes, descriptions et tableaux.
