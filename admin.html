Gestion du catalogue Chinguitel

Modifier les informations du catalogue sans toucher au code du site.

1. Ouvrir le catalogue

Aucune clé GitHub n’est nécessaire. La page charge simplement les informations publiques du catalogue. Pour publier une modification, vous téléchargerez ensuite le fichier mis à jour et le remplacerez sur GitHub.

2. Modifier les informations

Changez les informations directement ici : prix, volumes Internet, minutes, SMS, validités, codes, descriptions et tableaux.

3. Mettre les modifications sur le site

1
Télécharger le fichier mis à jour
Cliquez sur « Télécharger les données » ci-dessous.
2
Ouvrir le fichier services.json sur GitHub
Le bouton ci-dessous ouvre directement la page où le fichier peut être remplacé.
3
Remplacer le contenu et enregistrer
Sur GitHub, ouvrez la modification du fichier, remplacez son contenu par le fichier téléchargé, puis validez. Le catalogue public se mettra ensuite à jour automatiquement.
